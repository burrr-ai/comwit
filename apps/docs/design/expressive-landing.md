# Comwit expressive landing

## Brief

An expressive, Awwwards-inspired landing with very little explanatory copy. The landing presents Comwit; State and UI links open their documentation immediately. The panda belongs to State. Its original animated landing is preserved beside the persistent documentation sidebar, including the counter, code tabs and lower-page sections. Header geometry is shared across all routes; only its colors change.

## Research

- [Awwwards](https://www.awwwards.com/): oversized editorial typography, clear visual hierarchy, and a single dominant visual.
- [Moto Finance on Awwwards](https://www.awwwards.com/sites/moto-finance) / [live site](https://www.moto-card.com/): a concise headline paired with a full-scale tactile visual. Inspected September 24, 2026.
- [Invisible North on Awwwards](https://www.awwwards.com/sites/invisible-north) / [live site](https://invisiblenorth.com/): edge-to-edge type, image overlap, and a strong sense of scale. The award listing and current live site are references, not claims that the current live design is unchanged since its award.
- [Archivo](https://fonts.google.com/specimen/Archivo): a variable display face for the oversized wordmark. Interface reading text keeps the established docs typography. The OG card uses Archivo Black with its OFL license stored beside the font.

## Direction

A lime and ink graphic poster with oversized Archivo lettering and an original tactile sculpture. Motion is limited to the wordmark, floating artwork, and hover/focus feedback. State and UI each have a large documentation link. Reduced-motion preference, page visibility, and a manual pause control stop decorative motion. Mobile keeps both documentation destinations directly accessible.

## Generated asset

- File: `apps/docs/public/art/comwit-play-sculpture.webp`
- Tool: built-in ImageGen. The generated PNG had genuine alpha transparency; WebP conversion retained that alpha and reduced the transfer size to about 172 KB.
- Usage: landing hero and generated social card.

### Final generation prompt

Use case: stylized-concept. Asset type: isolated art-directed 3D sculpture for an experimental editorial web poster. Output a genuine transparent background, landscape 1536x1024, no backdrop or floor. One striking, oversized composition of three inflated matte-black interlocking ribbon loops, a sculptural soft architectural knot, with one smooth ivory rounded rectangular piece threaded through it. An original, bold silhouette: thick tubular forms, generous negative holes, some flat ends and sharp little creases, inviting tactile rubber and ceramic materials. Black shapes are rich charcoal with convincing soft studio highlights, visible fine grain, and subtle lime-green reflected light along selected edges. Real depth, dramatic overlap, high-end physical product photography mixed with a playful avant-garde graphic sculpture. Entire object occupies the middle 85% of the frame, with all its edges visible and 8% transparent padding. Camera sees the sculpture at a dynamic three-quarter angle; forms flow diagonally from bottom left to upper right. It must remain readable as a silhouette at 400px wide. This is a graphic centerpiece for a creative coding brand: bold, playful and memorable. No glass, no chrome, no neon holograms, no torus on a pedestal, no colored background, no text, no logos, no UI screens, no watermarks, no animals or people. The final asset must have real alpha transparency, not a checkerboard illustration.
