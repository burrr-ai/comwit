# 도메인 하나, 훅 하나.

comwit은 바이브 코딩을 위해 만든 React와 Next.js용 상태 관리 라이브러리입니다. 코딩 에이전트에게 [`llms.txt`](/state/llms.txt)를 전달하세요. 핵심 인터페이스, 도메인 구조, 개발을 시작하는 데 필요한 예제를 간결한 가이드 하나에 담았습니다.

**1,000개 이상의 프로젝트**에서 사용하는 [comwit.io](https://comwit.io) 바이브 코딩 플랫폼을 뒷받침합니다. [burrr.ai](https://burrr.ai)가 후원합니다.

<a id="the-interface"></a>

## 인터페이스

```tsx
// Load when the view mounts. Render the query state directly.
const products = useProduct((s) => s.products.load(filter))

// Read existing data without starting a request.
const detail = useProduct((s) => s.detail.data)

// Keep mutations and side effects in the domain.
const actions = useProduct((s) => s.actions)
```

도메인은 타입, 초기 상태, 액션을 정의합니다. `create()`는 이를 하나의 훅으로 결합합니다. 액션은 상태를 직접 변경하고 컴포넌트는 사용하는 필드를 구독합니다. `ComwitProvider` 하나가 앱 상태의 범위를 정하고 모델은 접근할 때 초기화됩니다.

<a id="pick-the-data-flow"></a>

## 데이터 흐름 선택

| 필요한 작업                                | 사용할 API                                                                                            |
| ------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| 마운트된 화면의 데이터 가져오기            | [`query()` + `.load(arg)`](/state/docs/api/query)                                                     |
| Server Component가 가져온 데이터 렌더링    | [`useDomain.hydrate(...)`](/state/docs/guide/nextjs)                                                  |
| 쿼리와 함께 Suspense 경계 스트리밍(실험적) | [`.suspend(arg)` + `useServerInsertedHTML`](/state/docs/guide/nextjs#streaming-suspense-experimental) |
| 정확한 IndexedDB 스냅샷 복원 및 재검증     | [`local.query()`](/state/docs/api/local)                                                              |
| API 호출 없이 캐시 데이터 복원             | [`local()` + `.restore(arg)`](/state/docs/api/local)                                                  |
| 환경설정이나 로컬 초안 저장                | [`persist()`](/state/docs/api/persist)                                                                |
| 명령, 낙관적 갱신, 여러 요청 실행          | [`action()`](/state/docs/api/action)                                                                  |

관련 목록, 상세, 필터, UI 상태는 같은 도메인에 유지합니다. 기능에 필요할 때 파생 값, 유효성 검사, 실행 취소/다시 실행, 액션 데코레이터를 추가하세요.

<a id="start-building"></a>

## 개발 시작하기

- [빠른 시작](/state/docs/guide/quickstart) — 설치하고 도메인을 만든 뒤 렌더링합니다.
- [LLM 설정](/state/docs/llm-setup) — 파일 하나로 에이전트에 인터페이스를 전달합니다.
- [프로젝트 구조](/state/docs/guide/structure) — 도메인 하나에서 완성된 앱으로 확장합니다.
