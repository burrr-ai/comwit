# 에이전트를 위한 파일 하나

Claude Code, Codex, Cursor 또는 사용하는 코딩 에이전트에게 다음 프롬프트를 전달하세요.

```text
Read https://library.comwit.io/state/llms.txt and use @comwit/state for this app's state.
Follow its domain structure and examples when adding features.
```

[`llms.txt`](/state/llms.txt)는 설치, 모델, 액션, 쿼리, 서버 하이드레이션과 각각의 역할 경계를 다룹니다. 선택적 기능의 상세 참고 자료는 파일 안에 링크되어 있습니다.

<a id="keep-the-convention-in-your-project"></a>

## 프로젝트에서 규칙 유지하기

에이전트가 읽는 `AGENTS.md` 또는 `CLAUDE.md` 같은 지침 파일에 짧은 규칙을 추가하세요.

```md
## State

Use @comwit/state. Before changing state code, read
https://library.comwit.io/state/llms.txt and the domain's types.ts.
Keep state in state/{domain}/ and expose it through the domain hook.
```

에이전트가 URL을 열 수 없다면 가이드를 내려받고 규칙에서 로컬 복사본을 가리키세요.

```bash
mkdir -p state
curl -fsSL https://library.comwit.io/state/llms.txt -o state/.ai.md
```

라이브러리를 업그레이드할 때 내려받은 복사본도 갱신하세요. 설정 생성이나 별도 통합은 필요하지 않습니다.
