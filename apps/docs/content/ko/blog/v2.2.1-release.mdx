## 재검증 중에도 기준 필드를 유지합니다

이제 `local.query()`와 `local.infinite()`는 원격 결과가 관찰되기 전에 컬렉션의 엔티티 병합 규칙을 적용합니다. 상세 리소스나 로컬 변경으로 이미 저장한 필드가 일부 목록 응답 때문에 잠깐 사라지지 않습니다.

모든 `AsyncIterable` 청크에도 같은 보장이 적용됩니다. 백그라운드 스트리밍 갱신이 새 필드와 뷰 메타데이터를 점진적으로 제공하는 동안에도 로컬 우선 화면은 저장된 엔티티 데이터를 계속 보여 줍니다.

원격 조각에 명시한 속성은 여전히 기준 값을 갱신하거나 비웁니다. 기본 얕은 병합은 생략한 속성만 보존하며, 사용자 정의 `merge`와 `revision` 정책이 계속 우선합니다.

업그레이드:

```bash
yarn add @comwit/state@2.2.1
```

정규화된 컬렉션과 재검증 동작은 전체 [`local()` 레퍼런스](/docs/api/local)를 참고하세요.
