## 새로운 기능

<a id="suspense-support"></a>

### Suspense 지원

`query()`와 `query.infinite()`에 `suspense: true` 옵션이 추가됐습니다. 새 훅 없이 기존 `useModel()` / `create()` API에서 바로 사용할 수 있습니다.

```ts
const userModel = model({
  profile: query<User>({
    initialData: null,
    queryFn: () => fetch('/api/user').then((r) => r.json()),
    suspense: true,
  }),
})
```

- React `<Suspense>`, `<ErrorBoundary>`와 자연스럽게 통합됩니다.
- 다시 조회할 때는 중단하지 않고, 기존 데이터를 보여 주면서 백그라운드에서 가져옵니다.
- TypeScript가 `data`를 자동으로 `NonNullable<T>`로 좁힙니다.
- 같은 모델에서 Suspense 쿼리와 일반 쿼리를 함께 사용할 수 있습니다.

<a id="real-time-subscriptions"></a>

### 실시간 구독

`query.realtime()`으로 WebSocket, SSE 등 실시간 데이터 소스를 쿼리 패턴에 연결할 수 있습니다.

```ts
const chatModel = model({
  messages: query.realtime<Message[]>({
    initialData: [],
    queryFn: () => fetch('/api/messages').then((r) => r.json()),
    subscribe: (callbacks) => {
      const ws = new WebSocket('wss://api.example.com/chat')
      ws.onmessage = (e) => {
        callbacks.update((prev) => [...prev, JSON.parse(e.data)])
      }
      ws.onopen = () => callbacks.onStatus('connected')
      ws.onclose = () => callbacks.onStatus('disconnected')
      return () => ws.close()
    },
  }),
})
```

- `connectionStatus` / `isConnected` 상태를 자동 관리합니다.
- `update()`, `set()`, `refetch()`, `onStatus()`, `onError()` 콜백을 제공합니다.
- `unsubscribe()`로 직접 정리할 수 있으며, 다시 조회하면 이전 구독은 자동으로 정리됩니다.
- `query()` / `query.infinite()`와 같은 API 패턴을 사용합니다.

<a id="persist-plugin"></a>

### Persist 플러그인

`persist()` 필드 선언은 모델 상태를 외부 저장소에 자동으로 동기화합니다.

```ts
const settingsModel = model({
  theme: persist<'light' | 'dark'>({
    key: 'app-theme',
    defaultValue: 'light',
  }),
  sidebarOpen: persist<boolean>({
    key: 'sidebar-open',
    defaultValue: true,
    storage: 'sessionStorage',
  }),
})
```

- `localStorage` / `sessionStorage` 어댑터를 기본 제공합니다.
- `PersistAdapter`로 IndexedDB, 쿠키 등 사용자 정의 저장소를 연결합니다.
- localStorage에서 탭 사이 동기화를 지원합니다.
- 쓰기를 디바운스하고 SSR에서도 안전하게 동작합니다.
- `serialize` / `deserialize`를 직접 지정할 수 있습니다.

<a id="new-decorators"></a>

### 새 데코레이터

- `@Retry`: 최대 시도 횟수와 지연을 설정하는 자동 재시도
- `@Queue`: 동시 실행을 막고 순서대로 처리
- `@Log`: 메서드 호출 기록
- `@Validate`: 입력 검증

전역 인터셉터, 파생 상태, 모델 검증도 추가했습니다.

<a id="architecture-plugin-system"></a>

## 아키텍처: 플러그인 시스템

v0.2.0의 가장 큰 구조 변화입니다.

이전에는 Suspense, 실시간 구독, 영속화 같은 기능을 추가하려면 `model.ts`, `query.ts`, `action.ts`, `provider.tsx`를 함께 수정해야 했습니다. 이제 핵심 코드를 건드리지 않고 `FieldPlugin` 인터페이스로 기능을 등록합니다.

```ts
type FieldPlugin = {
  name: string
  detect(value, path, bag): { initialValue } | null
  createRegistryState(defaults?): unknown
  bindState(proxy, bag, state, defaults): object
  onRender?(bag, state): void
}
```

`query`, `persist`, `realtime`은 모두 이 플러그인 시스템 위에서 동작합니다. 외부 플러그인도 `registerPlugin()`으로 comwit을 확장할 수 있습니다.

valtio 의존성도 완전히 제거하고 프록시 기반 반응성 엔진을 직접 구현했습니다.

<a id="bug-fixes"></a>

## 버그 수정

- 쿼리 `isLoading` 계산 순서를 수정해 오류 후 재시도에서도 로딩 상태를 올바르게 표시합니다.
- 쿼리 인자가 빠르게 바뀔 때 오래된 응답이 덮어쓰지 않도록 최신 응답만 적용합니다.
- `set()`이 캐시와 동기화되어 `staleTime` 안에서 읽으면 이전 캐시가 아닌 설정한 데이터를 반환합니다.
- 무한 쿼리의 `withCursor`를 제거하고 `hasMore` 가드를 추가했습니다.
- `nextFetch` 커서 기록을 수정해 여러 단계 뒤로 이동할 수 있습니다.
