Comwit State와 Comwit UI가 이제 저장소와 문서 사이트를 공유합니다.

- [State](/state)는 판다, 가이드, API 참고 문서를 유지합니다.
- [UI](/ui)는 수정 가능한 컴포넌트, 실시간 예제, 테마 플레이그라운드를 제공합니다.
- 제품마다 자체 에이전트 가이드가 있습니다. [State llms.txt](/state/llms.txt)와 [UI llms.txt](/ui/llms.txt)를 확인하세요.

워크스페이스는 pnpm을 사용하며 소스는 `packages/state`와 `packages/ui` 아래에 나뉘어 있습니다. 공개 패키지 이름과 버전은 서로 독립적으로 유지합니다. 사용을 종료한 `comwit` 호환성 래퍼는 워크스페이스에서 제거했습니다. `@comwit/state`를 사용하세요.

기존 State 문서와 에이전트 URL은 리디렉션을 통해 계속 사용할 수 있습니다. UI 컴포넌트 소스는 기존처럼 `comwit-ui`로 프로젝트에 설치하며 직접 수정할 수 있습니다.

이번 변경은 저장소와 문서의 통합이며 새로운 npm 패키지 버전은 아닙니다.
