## 형제 Suspense 경계의 로딩이 정상 완료됩니다

한 경계가 이미 폴백을 표시하는 동안 effect에서 두 번째 대기 경계를 마운트하면
반복 렌더링으로 탭이 멈출 수 있었습니다. 같은 카테고리 쿼리를 기다리는
쇼핑몰 헤더와 상품 경로 표시에서도 발생할 수 있는 문제입니다.

React 19에서 `.suspend()`는 이제 React의 `use()`로 진행 중인 쿼리를 기다립니다.
여러 쿼리 키를 사용하는 셀렉터도 서버 스트리밍을 포함해 모든 결과를 기다립니다.
React 18은 기존 동작을 유지합니다.

## 업데이트 방법

의존성과 잠금 파일을 업데이트하면 됩니다. 앱 코드의 마이그레이션은 필요 없습니다.
대기 상태가 되는 트리를 렌더링하거나 업데이트하는 테스트에서는 React의
비동기 `act()`를 await하여 대기 중인 작업이 완료되도록 하세요.

회귀 테스트와 스트리밍 테스트를 포함한 State 전체 테스트 38개 파일의 487개 테스트가
통과했습니다. 타입 검사와 프로덕션 빌드도 통과했습니다.

재현 방법은 [PR #139](https://github.com/burrr-ai/comwit/pull/139)와
[이슈 #138](https://github.com/burrr-ai/comwit/issues/138)을 참고하세요.
