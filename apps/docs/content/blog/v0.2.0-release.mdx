## What's New

### Suspense Support

`query()`와 `query.infinite()`에 `suspense: true` 옵션이 추가되었습니다. 별도 hook 없이 기존 `useModel()` / `create()`에서 바로 동작합니다.

```ts
const userModel = model({
  profile: query<User>({
    initialData: null,
    queryFn: () => fetch('/api/user').then((r) => r.json()),
    suspense: true,
  }),
})
```

- React `<Suspense>`와 `<ErrorBoundary>`에 자연스럽게 통합
- Refetch는 suspend하지 않음 — 기존 데이터를 보여주면서 백그라운드 갱신
- TypeScript에서 `data`가 `NonNullable<T>`로 자동 추론
- 같은 모델 안에서 suspense / non-suspense 쿼리 혼용 가능

### Real-time Subscriptions

`query.realtime()`로 WebSocket, SSE 등 실시간 데이터 소스를 query 패턴에 통합할 수 있습니다.

```ts
const chatModel = model({
  messages: query.realtime<Message[]>({
    initialData: [],
    queryFn: () => fetch('/api/messages').then((r) => r.json()),
    subscribe: (callbacks) => {
      const ws = new WebSocket('wss://api.example.com/chat')
      ws.onmessage = (e) => {
        callbacks.update((prev) => [...prev, JSON.parse(e.data)])
      }
      ws.onopen = () => callbacks.onStatus('connected')
      ws.onclose = () => callbacks.onStatus('disconnected')
      return () => ws.close()
    },
  }),
})
```

- `connectionStatus` / `isConnected` 상태 자동 관리
- `update()`, `set()`, `refetch()`, `onStatus()`, `onError()` 콜백
- `unsubscribe()`로 수동 정리, re-query 시 이전 구독 자동 정리
- 기존 `query()` / `query.infinite()`와 동일한 API 패턴

### Persist Plugin

`persist()` 필드 디스크립터로 모델 상태를 외부 스토리지에 자동 동기화합니다.

```ts
const settingsModel = model({
  theme: persist<'light' | 'dark'>({
    key: 'app-theme',
    defaultValue: 'light',
  }),
  sidebarOpen: persist<boolean>({
    key: 'sidebar-open',
    defaultValue: true,
    storage: 'sessionStorage',
  }),
})
```

- `localStorage` / `sessionStorage` 기본 어댑터
- 커스텀 `PersistAdapter` 인터페이스 (IndexedDB, cookies 등)
- 크로스탭 동기화 (localStorage)
- 디바운스 write-back, SSR 안전
- 커스텀 `serialize` / `deserialize`

### New Decorators

- `@Retry` — 실패 시 자동 재시도 (최대 횟수, 딜레이 설정)
- `@Queue` — 동시 실행 방지, 순차 실행 보장
- `@Log` — 메서드 호출 로깅
- `@Validate` — 입력 검증

글로벌 인터셉터, derived state, model validation도 추가되었습니다.

## Architecture: Plugin System

v0.2.0의 가장 큰 구조적 변화입니다.

기존에는 새 기능(suspense, realtime, persist)을 추가할 때마다 `model.ts`, `query.ts`, `action.ts`, `provider.tsx`를 모두 수정해야 했습니다. 이제 `FieldPlugin` 인터페이스를 통해 코어 수정 없이 기능을 등록합니다.

```ts
type FieldPlugin = {
  name: string
  detect(value, path, bag): { initialValue } | null
  createRegistryState(defaults?): unknown
  bindState(proxy, bag, state, defaults): object
  onRender?(bag, state): void
}
```

`query`, `persist`, `realtime`이 모두 이 플러그인 시스템 위에서 동작합니다. 서드파티 플러그인도 `registerPlugin()`으로 확장 가능합니다.

또한 valtio 의존성을 완전히 제거하고, 자체 프록시 기반 반응성 엔진을 구현했습니다.

## Bug Fixes

- query `isLoading` 계산 순서 수정 — error-retry 시 로딩 상태 정상 표시
- stale response race condition — 빠른 query arg 변경 시 최신 응답만 반영
- `set()` 호출 시 캐시 동기화 — staleTime 내 읽기 시 set 데이터 유지
- infinite query `withCursor` 제거, `hasMore` 가드 추가
- `nextFetch` cursor history — 다단계 뒤로가기 네비게이션 지원
