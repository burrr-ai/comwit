# Yoshi

Yarn workspaces monorepo for Yoshi — an LLM-friendly React state management library.

## Structure

- `packages/comwit` — Core library (`comwit`)
- `apps/docs` — Documentation site (Next.js + Tailwind)
- `apps/playground` — Playground app for testing

## Commands

- `yarn build` — Build all workspaces
- `yarn dev:lib` — Watch-build the library
- `yarn dev:docs` — Run the docs site
- `yarn dev:playground` — Run the playground app
